# AntiCheatCheck

Studio client panel for testing an anti-cheat in your own Roblox place. The script exits immediately outside Roblox Studio.

Paste `AntiCheatTester.lua` into a LocalScript at `StarterPlayer > StarterPlayerScripts`.

Right Shift hides and shows the panel. `Disable All Tests` on the Home tab resets everything.

## Tabs

- **Combat**: aimbot with Head / Chest / Root targeting, Smooth / Snap / Soft modes, Always or Hold-RMB activation, Crosshair / Distance / Health priority, sticky aim, team check, wall check, FOV, smoothness, soft-aim strength, and velocity prediction. Triggerbot fires the equipped Tool with a configurable reaction delay and fire interval.
- **Visuals**: player highlights, tracer lines, 2D boxes, username / HP labels, x-ray walls, hitbox expander, targeted ESP, and look-at inventory.
- **Move**: freecam, WalkSpeed, fly, noclip, jump power, infinite jump, teleport forward, teleport to ESP target, Ctrl+Click teleport, CFrame speed, dash, and rapid spin.
- **Stats**: scans common stat names under the local player and tests local edits.
